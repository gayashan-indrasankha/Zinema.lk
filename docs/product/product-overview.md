# Product Overview

## What Zinema.lk Is

Zinema.lk – Modern Full-Stack Movie Streaming Platform is a planned web platform for browsing, discovering, managing, and streaming movie and series content. It will provide a viewer-facing experience, authenticated user features, and an administration workspace for catalog and media operations.

## Problem It Solves

Streaming platforms need more than a list of videos. They need searchable catalogs, clean detail pages, reliable playback, user engagement features, and operational tools for managing content at scale.

Zinema.lk aims to solve these needs by combining:

- A fast public browsing experience.
- Structured movie and series metadata.
- User accounts, watchlists, reviews, and ratings.
- Administrative tools for catalog and media management.
- A video processing pipeline that prepares uploaded media for HLS playback.
- Reporting and dashboards for platform visibility.

## Target Users

- Public visitors who want to discover movies, series, trailers, and collections.
- Registered viewers who want saved lists, reviews, ratings, and viewing activity.
- Administrators who manage content, media files, publication state, and platform settings.
- Platform operators who need visibility into content performance, processing health, and user activity.

## Core Product Scope

The core product scope includes:

- Public movie and series browsing.
- Detail pages with metadata, posters, trailers, ratings, and related content.
- Search and filtering by title, genre, year, type, and availability.
- Watch pages with HLS playback.
- User registration, login, profiles, and role-based access.
- Watchlists, reviews, ratings, and comments.
- Admin catalog management.
- Media upload and processing workflow.
- Operational dashboard and reports.

## MVP Scope

The MVP should focus on proving the complete content lifecycle:

- Public home, browse, search, and details pages.
- Authentication and user profile basics.
- Admin movie and series management.
- Media upload records and processing status.
- FFmpeg-based HLS processing flow.
- Watch page with secure playback URL handling.
- Basic reviews, ratings, and watchlist features.
- Dashboard summary for content and processing state.
- Docker-based local environment.
- GitHub Actions checks for build and test confidence.

## Future Scope

Future phases can extend the product with:

- Personalized recommendations.
- Advanced collections and curated rows.
- Subscription or payment workflows.
- Rich notification preferences.
- Editorial content and promotional placements.
- Advanced analytics and content performance reporting.
- Multi-language metadata.
- Offline processing dashboards.
- Moderation workflows for user-generated content.
- Mobile app API support.
